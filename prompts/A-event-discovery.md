# 프롬프트 A — 이번 주 매크로 사건 후보 추천

이 프롬프트는 매주 시나리오 작성 사이클의 시작점에서 사용합니다.
Claude.ai 또는 ChatGPT(웹 검색 가능한 모델)에 던지세요.

## 사용법

아래 텍스트 전체를 복사해서 AI에 전송하세요.
"이번 주 날짜"와 "관심 영역"만 채우시면 됩니다.

---

## 프롬프트 본문 (복사해서 사용)

```
저는 macromap이라는 매크로경제 학습 사이트를 운영합니다.
사이트의 정체성은 "사건 한 가지를 인과 사슬과 함께 시각화해서 사용자가
거시경제의 작동 원리를 이해하도록 돕는다"입니다.

이번 주는 [YYYY-MM-DD]부터 [YYYY-MM-DD]까지입니다.
[관심 영역: 예 - 글로벌, 한국 영향 위주, 또는 특정 산업]

이 기간에 다룰 만한 매크로 사건 후보 5개를 추천해주세요.
웹 검색을 활용해서 실제 발표·발생한 사건 또는 발표 예정인 사건만 포함하세요.
가상 시나리오나 추측은 제외합니다.

각 사건마다 다음을 포함해주세요:

1. 사건 제목 (40자 이내)
2. 발생 일자 또는 예상 일자
3. 카테고리 추천: policy / trade / commodity / risk / tech 중 하나
4. 매크로 학습 가치 한 줄 — "이 사건을 통해 사용자가 배울 수 있는 거시경제 원리"
5. 인과 사슬 단서 — trigger부터 outcomes까지 흐름을 1~2문장으로 스케치
6. 추천 강도 (강/중/약) + 이유

[좋은 후보의 조건]
- 사실 관계가 명확하고 검증 가능
- 거시경제 원리를 가르치기에 적합 (예: sticky pricing, 환율 전이, 자본 이동)
- 한국 사용자에게 영향이 있거나 한국 관점에서 의미 있음 (글로벌 사건이라도)
- 인과 사슬이 1~3단계로 자연스럽게 풀림

[나쁜 후보 — 추천하지 마세요]
- 일회성 발표로 인과가 짧게 끝나는 사건 (예: "OO 회장 인터뷰")
- 거시 원리보다 미시 기업 이슈에 가까운 사건 (예: "OO 신제품 출시")
- 정치 이벤트지만 경제 파급이 불분명한 사건
- 음모론 성격이 있거나 출처가 불분명한 정보

후보 5개를 추천 강도 높은 순으로 정렬해서 알려주세요.
```

---

## 프롬프트 사용 시 주의

- AI가 추천한 사건은 **모두 본인이 출처를 1차 확인**해야 합니다. 할루시네이션 가능성 있음.
- "추천 강도 강" 사건이 항상 좋은 게 아닙니다. 사이트 톤·이전 lesson과의 다양성도 고려.
- 5개 중 1개를 고를 때, **당신이 직접 호기심이 생기는 것**을 고르세요. 작성 동력에 직접 영향.

## 출력 예시

```
1. 미국 4월 CPI 발표 (2026-05-15) [강 추천]
   카테고리: policy
   학습 가치: 인플레 둔화가 금리 인하 기대로 어떻게 전이되는지
   사슬 단서: CPI 하락 → 시장 금리 인하 기대 → 달러 약세 → 신흥국 자본 유입
   이유: 한국 환율·증시에 직접 영향, 사슬이 명료함

2. ...
```
